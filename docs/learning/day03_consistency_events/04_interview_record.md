# Day 3 面试记录

## 结论

Day 3 是后端一致性基础日，新增内容包括状态机、幂等键、乐观锁、Unit of Work、数据库约束和审计事件。

这些能力会成为未来 Agent 的执行边界，但今天没有新增 Agent Loop、AgentState、Context、Tool、Observation、Memory、RAG、人机中断恢复或 Agent 评估能力。

按照 `AGENTS.md` 的规则：

- 只问 Agent 相关问题；
- Router、Service、Repository、数据库、事务、幂等和普通异常处理直接讲解，不作为面试题；
- 不能为了每日提问数量用后端问题冒充 Agent 面试。

因此 Day 3 不安排面试问题。原理、关键代码、错误修复和测试证据已经分别记录在本目录其他三份文档中。
