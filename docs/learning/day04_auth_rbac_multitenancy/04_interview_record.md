# Day 4 面试记录

## 结论

Day 4 新增的是后端安全基础设施：

- JWT 认证；
- RBAC；
- 资源级鉴权；
- tenant-scoped Unit of Work/Repository；
- 授权审计；
- 开发态身份；
- 安全配置和越权测试。

这些能力会成为未来 Agent Tool 的强制安全边界，但今天没有新增 Agent Loop、AgentState、Context、Memory、RAG、Observation、计划修订、人机暂停恢复或 Agent 评估能力。

按照 `AGENTS.md`：

- 面试题只问 Agent 相关内容；
- 认证、权限、数据库、事务、多租户和普通后端异常由 Codex 直接完整讲解；
- 不能为了每日流程用后端题目冒充 Agent 面试题。

因此 Day 4 不安排面试问题。原理、关键代码、真实失败和测试证据已记录在本目录其他三份文档中。
